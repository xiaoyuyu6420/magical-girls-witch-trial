# 手机端答题页：纵向极致挤压（对齐电脑端）

## 背景与根因（一句话版）
电脑端"好"靠三根支柱：①选项 `flex:1` 撑满空间 ②选中 `flex:8` 膨胀、未选 `flex:0.01` 塌缩的挤压反馈 ③居中纪念碑式内容。
这些规则**全局已存在**（`globals.css:378-385`），但手机端在媒体查询里用 `flex:0 0 auto` + 三处 `!important` 把它们**全部禁用**了，并改成了"列表小条"；再加上触屏反馈延迟只有 120/280ms（桌面是 400/700ms），即使有动画也看不清。

## 改动清单

### 文件1：`src/app/globals.css`（核心）

**A. 解除挤压禁用，让选项填满高度**（`@media (max-width:768px)` 块，504-564）
- 第 523-530 行 `.options-stage`：`flex: 0 0 auto` → **`flex: 1`**（吃满题目下方剩余高度，这是挤压的前提）；`gap` 从 `0.6rem` 调小到 `0`（挤压时不靠 gap 控制间距，靠 flex 值）；保留 `flex-direction:column`、`width:100%`、`padding`。
- 第 531-535 行 `.opt-block`：`flex: 0 0 auto` → **`flex: 1`**（默认等分高度，选中/未选交给全局 `flex:8`/`flex:0.01`）；保留 `min-height:0`、`border-radius`。
- 第 540 行 `.opt-block.is-selected { flex: 0 0 auto !important }`：**删除该条整行**（让全局 379 行 `flex:8 !important` 重新生效）。
- 第 541 行 `.opt-block.is-dimmed { flex: 0 0 auto !important; min-height:0 }`：**删除该条整行**（让全局 384 行 `flex:0.01 !important` 生效，塌成细缝）。
- 第 542 行 `.opt-block.is-dimmed .opt-content { max-height:0; padding:0; overflow:hidden }`：**删除**（全局 385 行已有 `opacity:0 !important`，塌缩后内容自动不可见）。

**B. 内容恢复居中纪念碑式**（`@media (max-width:768px)` 块）
- 第 536 行 `.opt-content`：从 `position:relative; flex-direction:row; align-items:center; gap:0.8rem; padding:0.7rem 1rem; max-width:none` → 改为**保持在流内但居中**：`position:relative; width:90%; max-width:340px; padding:0; text-align:center; display:flex; flex-direction:column; align-items:center; gap:0.4rem`（复刻桌面 368 行的纪念碑观感，靠父级 `.opt-block` 的 `justify-content:center; align-items:center` 居中）。
- 第 537 行 `.opt-index`：从 `font-size:1.1rem; opacity:0.45` → **`font-size:clamp(2rem,7vw,3rem); opacity:0.18; margin-bottom:0.5rem`**（大号低透明罗马数字，对齐桌面 369 行）。
- 第 538 行 `.opt-text`：从 `text-align:left; opacity:0.92` → **`text-align:center; opacity:0.85; font-size:clamp(0.9rem,3.8vw,1.05rem)`**。

**C. 让挤压动画跑起来 + 取消垂直居中留白**（`@media (max-width:768px),(pointer:coarse)` 块，590-627）
- 第 591 行 `#test-stage-wrapper { ... justify-content: center }`：`center` → **`flex-start`**（题目在顶部、选项区 `flex:1` 吃掉剩余高度，消除上下留白）。
- 第 601 行 `.opt-block` 的 `transition`：当前**没有 `flex`**（导致挤压瞬跳）→ **加入 `flex 0.5s var(--ease-out-expo)`**，改为 `transition: flex 0.5s var(--ease-out-expo), background 0.16s ease, border-color 0.16s ease, opacity 0.16s ease, transform 0.16s ease`。
- 第 608-613 行 `.opt-block.is-selected`：**删除第 609 行 `flex: 0 0 auto !important` 和第 610 行 `transform: scale(0.985)`**（让全局 `flex:8` 膨胀生效）；保留金色背景/阴影（611-612 行）。
- 第 616-621 行 `.opt-block.is-dimmed`：**删除第 617 行 `flex: 0 0 auto !important`**（让全局 `flex:0.01` 塌缩生效）；622-624 行的 `.opt-content` opacity 覆盖可保留为兜底。
- 第 629-635 行整个 `@media (pointer:coarse) and (max-width:768px)` 块：**删除**（它在触屏恢复 dimmed 内容可见，与极致挤压的"塌缩不可见"冲突）。

**D. 不动的部分**：`is-selected` 全局金色高亮规则（378-383 行）、`is-dimmed` 全局塌缩规则（384-385 行）、`.opt-block` 桌面 `display:flex; justify-content:center`（355 行，手机继承）、入场动画 `animation:none`（596 行，本次不恢复）。

### 文件2：`src/components/TestScreen.tsx`
- 第 271-272 行触屏反馈延迟：`feedbackDelay: 120 → 300`、`totalDelay: 280 → 650`（~600ms 档，让 `flex 0.5s` 挤压动画基本可见后再 fade-out 进下一题）。

### 文件3：`tests/mobile.spec.ts`
- 第 55-59 行断言更新：`.opt-block` 默认 flex 从 `0 0 auto` → **`1`**（匹配新的 `flex:1`）；注释从"content-sized, not stretched"改为"equal-share flex:1 to support vertical squeeze"。

## 边界与不动项
- **scale 题（天平题，2 选项）**：复用同一套 `.opt-block`，自动获得纵向挤压，无需单独改。
- **weight 题（砝码三槽）**：走内联 style，不经过 `.opt-block`，不受影响。
- **长题干挤压**：第一题题干约 6-7 行（占 ~35vh），选项区有 ~55vh 可挤压，够用。若后续个别题题干过长挤压选项区，不在本次范围，单独处理。
- **桌面端（>768px）零改动**：所有改动都在媒体查询内，桌面行为完全不变。
