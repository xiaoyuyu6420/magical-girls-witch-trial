## 一、为什么会有这次重写

- 文案被有意清空（保留全部结构字段：维度/分值/向量/门控，清空全部文案字段），准备全量重写。
- 此前有过一次"全量重写"尝试（见 `crucible-archive/2026-08-11-0225-rewrite-all-copy-rollback/`），**技术上全绿被回滚**：G0–G4 自动闸全过、58 测试过、审计 PASS，但"调性/人味"这一维无法自动验证，用户亲手打回。

### 上次回滚的根因（必须记住）
1. **最难的约束天然不可机器验证**——"逼视感、人味、具体细节"没有任何 gate 覆盖，只能人眼兜底。
2. **subagent 在"别模板化"约束下制造新模板**——红蓝实测：否认态 90% 用"不对。"起手，承认态 57% 用"……是。"起手。统计闸能事后计数，生成时管不住。
3. **创作面积极大 × 机械约束极密**——26 题 × 3 态 + 21 角色 + UI × 四语言，每寸被冻结字段/位置断言/词表三层夹击。
4. **调性契约偏"方向感"而非可对账的 spec**——"人味不是戏腔"是 aspiration，不是可执行信号。
5. **方向连续变动两次**（trim → 全量 → 回滚），方向不稳比难度更耗人。

## 二、调性北极星（用户原话 + 提炼）

### 2.1 触发重写的起点（用户原话）
> "我把这个项目的文案应该是都清空了，我想不到为什么文案会这么难写。在开始之前，我觉得你需要帮我去看这个项目，然后定个调子：我到底要写什么？用户到底想看什么？想测些什么？"

### 2.2 产品哲学：魔法少女的阴暗内核（用户原话，最核心）
> "第二题……有那个味儿。"
> "对了，而且其实让我想到了很多东西，比如说校园霸凌等等一些非常不好的回忆。不过，我觉得这个方向是对的。毕竟很多魔法少女在现实中并不都是快乐的。甚至我们看魔法少女的受众，特别是现代的魔法少女，它的内核都是阴暗的，充满了大人世界里的残酷、痛苦、挣扎，还有现实的一些肮脏扭曲。所以我觉得这个方向是对的，而且挺有意思。"

**提炼**：这个测验的差异化 = 敢于触碰真实痛处。三重对齐：

| 层 | 内核 |
|---|---|
| 测验调性 | 审判官逼视你面对自己的阴暗面 |
| IP 内核 | 现代魔法少女 = 绝望、牺牲、残酷真相（不是少女贴贴） |
| 用户共鸣 | 触动真实痛处（霸凌、背叛、被丢弃） |

### 2.3 bad end 场景池（用户原话）
> "写全部吧，但是这次得吸取教训。选题其实可以不只是校园霸凌，还有家庭、社会、学校，甚至是朋友、小团体、同学、恋人。其实各种各样的 bad end 都挺有意思的"

**已分配的广度**：家庭(Q4/Q11) · 校园/小团体(Q5/Q7) · 社交(Q3) · 朋友/恋人(Q7/Q21) · 自我厌弃(Q12/Q16) · 背叛(Q7/Q21) · 绝望(Q6/Q20) · 偏执(Q10/Q24) · 牺牲(Q11/Q25) · 面具(Q16)。

### 2.4 逼视强度的定位（用户原话，关键决策）
> "我在想，这么问对一些不太想的人来说，这些东西其实是很痛苦的。现在题目属于一种没有那么痛苦，但是又让人难受的地步。我在想，要不就把我刚才写的狠一些，直面人的内心；要不就稍微缓和一些，让人不要那么痛苦，不然还做不完题目呢，对吧"

**决策：方向 A（更狠）+ 配套机制**（用户拍板"a"）。
- 中间态最尴尬：难受却没到深处，既不独特又劝退。
- **狠 = 从行为揭到动机与恐惧**，不是更多细节或更戏剧化（"判死刑"那种中二被否决过）。
- 配套机制（保完成率）：强度曲线（重题不连续）+ 三态本身就是心理出口（否认/狡辩可"体面地逃"）+ 变奏题喘息（天平/砝码）+ 批注插页大喘息 + 结果页接住 + 入口 content warning 筛选。

### 2.5 微反馈（用户原话）
> "a。在每一次的回答之后，要给用户一个反馈。我觉得这个反馈可以很小，可以和结果无关，但是得有"

**设计**：每题答完闪现审判官一句反应（1 行小字，与 700ms 动画并行不拖节奏），按三态从池中取（去重轮换），**与结果完全无关**（不剧透维度/分数）。每 5 题批注插页保留为大喘息。实现需 `_tone` 字段链路（yaml → sync → API → 前端）。

## 三、金标样例（调性锚点，后续每题对照）

### F1 复仇心（Q2，已锁定，用户确认"有那个味儿"）
> 别装了。你说放下了。可那些伤害过你的人，到现在一个都没忘——对吗？
> - 不对。没忘，不代表没放下。（否认 · score 1 · 释怀）
> - ……你说得对。我没真正放下过。（承认 · score 2）
> - 恨就是恨。凭什么要我原谅。（狡辩 · score 3 · 复仇）

### S1 严厉（Q1，已锁定，用户确认"门"方向）
> 别人一旦让你失望，你心里那扇门就关死了。你管这叫"原则"。可你从来没真正给过谁第二次机会——对吗？
> - 我没有。我给过很多人第二次机会。
> - ……也许吧。失望过的人，我确实很难再开门。
> - 第二次机会是给配得上的人。不是谁都配。

### 更狠版参考（Q4/Q6/Q7，用户"有感觉，但还需打磨"）
- **Q4 咽声**：你咽下那些话，不是因为你大度——是因为你怕。怕话说出口，对方翻脸；怕一吵起来，就没人要你了。你咽了这么多年，连你自己都快相信"我天生脾气好"了。对吗？
- **Q6 深渊**：你嘴上说会好起来的。可你心里清楚，你不是在熬，你是在等——等哪天真的撑不住了，就不用再装了。"再撑一下"这句话，你连自己都不信了。对吗？
- **Q7 背叛**：你说你信身边人。可你连别人递过来的一杯水，都要先想他图什么。你嘴上说"被伤过所以要防"——可你心里清楚，你不是防他，你是不敢信有人会无缘无故对你好。对吗？

**"更狠"的写法**：从行为层（"你咽着不说"）往下揭到动机/恐惧/自我欺骗（"你怕一开口就没人要你了"）。

## 五、防回滚机制（这次的硬保险）

1. **选题骨架先行**——26 题每题 bad end 场景 + 指控核心，用户确认后才动笔（骨架见下节附录）。
2. **起手词全库去重**——78 个起手词两两不同，写后跑脚本检查前 4 字重复。
3. **分批写、每批人审**——4-5 题/批，对照金标，过了才写下批。
4. **"更狠"对照**——每题检查是否揭到动机/恐惧层，而非停在行为层。
5. **工程闸复用**——`scripts/verify-rewrite.ts` 的 G0-G4（结构冻结/词表/IP词/四语言 key 镜像）仍可用作自动验收。
6. **金标不是"差不多就行"**——用户对度不满意就停下打磨，不强行批量。
