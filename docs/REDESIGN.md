# 魔女审判 → 灵魂审判器：产品重构方案

> 本文档总结了 2026-08-07 的完整共创讨论，作为后续执行的指导方案。
> 这不是"答题流程优化"，而是一次**产品定位升级**：从"某个IP的人格测试"变成"跨IP的灵魂审判平台"。

---

## 〇、一图看懂：这次到底要做什么

```
之前：魔法少女的魔女审判（单一IP人格测试）
        题目：第三人称叙事 → 用户"扮演"角色
        维度：审判/侵蚀/羁绊/觉醒（带魔女味）
        结果：匹配 13+2 魔女审判角色

之后：灵魂审判器（跨IP灵魂匹配平台）
        题目：审判官灵魂拷问 → 用户"面对"自己
        维度：通用心理维度（IP无关）
        结果：跨IP匹配（魔女审判/小圆/...）"你 = 某角色"
```

**核心转变**：题目从"替角色做决定"（扮演）变成"被审判官逼视自己"（面对）。这个心理指向的翻转，是一切改动的出发点。

---

## 一、痛点的真正根因（讨论回顾）

### 表面症状
用户做到第10题左右失去耐心，觉得"没新意"。

### 最初误判（已被推翻）
- ~~流程太长~~ → 总时长其实不是主因
- ~~交互太单一~~ → 是症状之一，不是根因
- ~~缺乏中途反馈~~ → 是症状之一，不是根因

### 真正根因
**题目让用户进入"替角色做决定"的扮演模式，而非"被逼视自己"的面对模式。**

对比 MBTI 为什么火：MBTI 每道题都指向用户本人（"你是否经常觉得自己不如别人"），用户答题时是在**审视真实的自己**，这个"看自己"的动作本身就是投入感来源。

而原项目的题目是第三人称叙事（"你被带入地下室……你会"），用户答题时是在**替一个虚构角色做决定**，是游戏化代入，不是自我审视。场景写得再好，用户心里始终是"如果她遇到这个情况"，而不是"如果是我"。

**这才是"感觉不到在描述我自己"的真正含义。**

## 二、题目层：审判官灵魂拷问模式（核心）

### 心理指向翻转

| | 扮演模式（现状） | 面对模式（目标） |
|---|---|---|
| 题干 | 第三人称场景叙述 | 审判官对"你"的直接逼问 |
| 选项 | 角色的反应台词 | 你被迫承认/否认/狡辩的剖白 |
| 用户心理 | 我在替这个角色决定 | 我在被审判，必须面对自己 |

### 四个关键技法
1. **审判官作为逼视者出场**——不是NPC，是心理压力源，他的话直接指向用户本人。
2. **断言式逼问**——不说"你会怎么做"，说"你从来没有真正X过，对吧？"，用断言逼用户回应。
3. **选项是"承认/否认/狡辩"三态**——不是"选A还是B"，是"面对这个指控你怎么回应"。
4. **场景退为氛围**——监牢、因子等IP元素还在，但只是渲染压力的环境，不是叙事主体。

### 标杆样例（F1 复仇心，用户确认"很有感觉"）

```
审判官：「别装了。你嘴上说'放下了'，可你记得每一个伤害过你的
         人的脸，记得他们说过的每一句话，记得当时的天气。
         你从来没有真正原谅过任何人——对吗？」

  ┌─────────────────────────────────────────┐
  │ 不对。我是真的放下了。记着不代表没放下。   │  ← 否认
  └─────────────────────────────────────────┘
  ┌─────────────────────────────────────────┐
  │ ……你说得对。我只是假装放下了。            │  ← 承认
  └─────────────────────────────────────────┘
  ┌─────────────────────────────────────────┐
  │ 我从不假装。恨就是恨，我凭什么要原谅。     │  ← 狡辩（合理化）
  └─────────────────────────────────────────┘
```

**为什么逼视**：审判官用"你记得每个人的脸、每句话、当时的天气"这种极具体的细节指控，让用户无处可躲。三个选项覆盖了人类面对"你从未原谅"的三种真实反应。

### 其他维度样例（S1 / B2 / W1 / 门控）

**S1 严厉度**——审判官指控"你的讲道理是虚伪的"：
> 「你一直觉得自己是个讲道理的人，对吧？可是你心里清楚——有些人，你从一开始就没打算给他们解释的机会。承认吧。你的'讲道理'，是有选择性的。」
> - ……不承认。我对谁都是先听再说。
> - 你说得对。有些人，我不屑于讲道理。
> - 我不是有选择性。是有些人不配被讲道理。

**B2 背叛感**——戳破"我重感情"的自我形象：
> 「你总说自己'很看重感情'。可我问你——上一次有人背叛你的时候，你心里冒出来的第一个念头，真的是'难过'吗？还是……'我早就知道了'？」
> - 是难过。被信任的人伤害，怎么可能不痛。
> - ……你猜对了。我第一反应是'果然如此'。
> - 我不'看重感情'。我只是害怕被丢下。

**W1 压抑力**——戳破"情绪稳定"的伪装：
> 「别人都以为你情绪稳定。但我知道——你不是稳定，你是在'压'。你把所有东西都压在一个连你自己都害怕的地方。我问你：那个地方，现在……还撑得住吗？」
> - 撑得住。我没有在'压'，我只是看得开。
> - ……快撑不住了。有时候自己都不知道在压什么。
> - 我没在压。我只是觉得大多数事不值得有情绪。

**门控题（情绪高潮）**——审判官最终逼问，决定特殊角色路径：
> 「审了这么久，你一直在回答'你会怎么做'。现在我问最后一个——如果你拥有摧毁一切的力量，而且不会被任何人阻止……你心里那个最深的念头，究竟是想要'毁灭'，还是想要'被看见'？」
> - 毁灭。我想把伤害过我的东西全部摧毁。（→ destroy 路径）
> - 被看见。我只是不想再一个人扛着。（→ endure 路径）
> - 都不是。我想要的是平静地活下去。（→ normal 路径）
> - ……我还没想好。这两个我都想要。（→ 第四选项，触发用）

**设计共性**：每道题都是审判官用具体细节指控一个关于用户的真相，选项是"否认/承认/狡辩（合理化）"三态，用户无处可躲必须亮明立场。

## 三、维度层：通用心理维度（IP无关化）

### 为什么要改
跨IP平台要求"不同IP的角色能放在同一空间比较"。现有12维度（审判/侵蚀/羁绊/觉醒）带魔女味（"因子""侵蚀"），无法容纳小圆等其他IP的角色。

### 改法
把现有维度**抽象化**，去掉IP专属命名，保留心理测量的本质。

| 现维度（魔女味） | → | 通用心理维度 | 测的是什么 |
|---|---|---|---|
| S1 严厉度 | → | 严厉/宽容倾向 | 对他人过错的反应 |
| S2 直觉度 | → | 直觉/理性倾向 | 决策依据 |
| S3 宽恕度 | → | 宽恕/惩戒倾向 | 面对冒犯的态度 |
| F1 复仇心 | → | 复仇/释怀倾向 | 被伤害后的反应 |
| F2 绝望度 | → | 绝望/韧性倾向 | 面对绝境的反应 |
| F3 执念度 | → | 执念/放下倾向 | 对目标的执着 |
| B1 信任度 | → | 信任/防备倾向 | 对他人的初始态度 |
| B2 背叛感 | → | 背叛敏感度 | 对背叛的反应强度 |
| B3 犠牲度 | → | 自我牺牲倾向 | 为他人付出的程度 |
| W1 压抑力 | → | 情绪压抑倾向 | 处理内心情绪的方式 |
| W2 理性力 | → | 理性维系倾向 | 用理性控制行为的程度 |
| W3 本能度 | → | 本能释放倾向 | 顺从本能的程度 |

**关键**：维度的**测量逻辑和分值不变**，只改命名和描述。加权曼哈顿距离算法可以复用。现有魔女审判角色的向量值不需要重算（它们在新维度名下数值一样）。

**调性差异说明**：四个 IP 调性差异大（小圆=黑暗宿命、毁灭者=废土御宅、憧憬=反套路黑喜剧、伊莉雅=Fate衍生日常）。跨 IP 匹配时，用户可能匹配到不熟悉调性的角色——这既是传播点（"我居然是PINK？"）也可能造成陌生感。结果页需处理好"陌生角色的介绍"。

### 跨IP匹配的核心问题
不同IP的角色，如何放在同一个通用心理维度空间比较？

**答案**：每个IP的角色，都由人工（或内容作者）**按通用心理维度打分**，形成该角色的12维向量。比如：
- 魔女审判 HIRO：[复仇心高, 绝望中, 执念极高, 信任低, ...]
- 小圆 晓美焰：[复仇心高, 绝望高, 执念极高, 信任选择性, ...]

两个角色虽然来自不同IP，但在同一套心理维度上有可比的向量。用户的答题向量与所有IP的所有角色向量计算距离，取最近的一个。

**这是内容工作量**（每个新IP的角色都要人工标定向量），不是工程难题。算法本身（加权曼哈顿距离）零改动。

### 跨IP匹配的匹配范围策略（待定）
- **全局匹配**：用户向量 vs 所有IP所有角色，取最近 → 结果可能来自任意IP（惊喜感强，但可能用户不熟的IP）
- **限定IP匹配**：用户先选IP，或系统按熟悉度筛选 → 结果可控
- **混合**：主结果限定，彩蛋可跨IP
**建议先全局匹配**（传播点在"跨IP惊喜"），但需观察用户反馈。

## 五、结果层：揭晓时刻（角色档案卡 + 动效揭晓）

### 心理契约的转变
题目要逼视（面对自己），但**结果页不该继续逼视**——结果页是审判结束后的揭晓时刻，情绪要从紧张反转为惊喜好玩。用审判腔包装结果页是用力过猛（v1/v2 被否决的教训），结果页应该干脆利落。

### 核心原则
- **结果页 = 揭晓时刻**，不是判决书。情绪从逼视反转为惊喜。
- **砍掉所有百分比/维度条/雷达图/top3 排行**——百分比让确定性的判决退化成模糊的相似度比拼，显得混乱。结果就是"你就是这个人"+"这个人是谁"，干净利落。
- **稀有度替代相似度**——"全球仅 3.4%"比"相似度87%"好玩，是游戏化传播点。
- 保留角色匹配（核心卖点）+ 分享卡功能 + 重新审判。

### 揭晓序列（结果页第一秒，最关键）

答完最后一题 → 揭晓序列。按 **interface-details skill motion-18（错峰浮现）**，6 个元素按情绪顺序错峰出场：

```
t=0.0s   答题页模糊淡出（motion-7，不是硬切）
t=0.8s   「审判结束了。」浮现
t=1.8s   「而你是——」浮现（留白制造悬念）
t=2.4s   角色名从模糊中浮现（ease-out-expo 曲线，和题目DNA一致）
            二 阶 堂 希 罗
t=3.0s   标语浮现（可选逐字描出，像手写判决 motion-3）
         「哪怕要死一千次，我也要把她带回来」
t=3.8s   来自《魔女审判》
t=4.2s   角色档案卡完整可用
```

**全程任意点击/按键即跳过**（motion-11，不强迫用户等）。

### 跨IP角色的处理
匹配到不熟IP的角色时，加一行**情绪式的作品介绍**（不是百科式）：

### 隐藏角色的彩蛋（easter-egg-3）
匹配到隐藏角色（2个特殊人格）时，揭晓动画升级——屏幕先出现"裂缝"光效，角色名带粒子碎裂感浮现，多一行「……审判庭从未见过这样的受审者」，稀有度显示「极少判定 · <0.5%」。普通角色克制，隐藏角色戏剧化，形成特殊感。

## 六、配套机制（与灵魂拷问编织）

这些不解决根因，但提升体验密度，缓解"单调感"：

### 审判官批注（中途反馈，替代氛围词）
每5题（第5/10/15题后），审判官停下说几句。基于已答倾向的**行为素描**（非维度标签），三次递进：
- 第5题后（试探）：「你回答时很少犹豫。这说明……你要么很清楚自己是谁，要么很擅长让自己看起来清楚。」
- 第10题后（逼近）：「有些题你答得太快了。快到像是在回避真正去想。」
- 第15题后（审判）：「你今天交出来的答案，有些连你自己都没承认过，对吧？」

**不输出维度标签/角色/百分比**（防剧透），只输出行为描写。

### 交互变奏

**天平题**（第8/22题）——审判官放下卷宗，灵魂二选一迫选：
```
审判官：「别想了。天平只会倾斜一次。你骨子里，到底是——」
┌──────────────┐    ┌──────────────┐
│ 「宁愿被骗    │    │ 「宁愿孤独    │
│   也不孤单」  │    │   也不冒险」  │
└──────────────┘    └──────────────┘
        二选其一，不可回头
```
左右两块选中一个→另一个被推开（复用 ease-out-expo 曲线 + is-selected/is-dimmed 推开逻辑，只是从3个变2个、从纵向变左右对峙）。选项是灵魂底色的二分，比三选项更迫人。

**砝码题**（第14题）——审判官给你"罪业之秤"，亲手称量自己：
```
审判官：「这台秤，你来拨。把分量，给你心里真正认同的那句话。」
「为了在乎的人，我可以变成坏人」  [●●●] 3
「我永远不会原谅蓄意的伤害」      [●]   1
「比起被爱，我更怕失去自我」      [ ]   0
拖动分配 · 总和必须 = 3
```
拖拽交互，与点选项完全不同。用户亲手"称量自己"的隐喻强化逼视感。只出现1次，作为流程中段重头戏。

### 节奏编排
26题里6个非标准节点（3批注+2天平+1砝码），每5题一个"不一样"的节点，打破单调。
