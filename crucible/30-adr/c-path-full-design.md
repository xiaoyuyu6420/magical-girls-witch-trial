# C 路径完整设计 —— 审判官灵魂拷问模式

> 把我们聊过的所有东西编织在一起：心理指向翻转（核心）+ 交互变奏（配套）+ 中途反馈（配套）+ 节奏编排。
> 题目样例覆盖审判/侵蚀/羁绊/觉醒四个模型，让你判断"这个模式放到各种维度上，是否都能逼视"。

---

## 〇、设计哲学（一句话）

**把"魔法少女审判"从一个叙事背景，变成一个正在发生的、对你本人的审判。**
用户不再是"在监牢里替角色做决定的扮演者"，而是"被审判官逼视、必须交出真实自己的受审者"。

---

## 一、心理指向翻转（核心机制）

### 当前题目的心理指向（扮演模式）
- 题干：第三人称场景叙述（"你被带入地下室……你会"）
- 选项：角色的反应台词（"冷冷地盯着屏幕""催动因子震碎机器"）
- 用户心理：我在替这个角色决定她该怎么做

### C 路径的心理指向（面对模式）
- 题干：审判官对"你"的直接逼问，场景退为氛围
- 选项：你本人被迫承认或否认的剖白
- 用户心理：我在被审判，必须面对真实的自己

### 翻转的关键技法
1. **审判官作为"逼视者"出场**——他不是NPC，他是心理压力源。他的话直接指向用户本人。
2. **断言式逼问**——审判官不说"你会怎么做"，他说"你从来没有真正X过，对吗？"——用断言逼用户承认或否认。
3. **选项是"承认/否认/狡辩"**——不是"角色会选A还是B"，而是"面对这个断言，你怎么回应"。
4. **场景退为氛围**——监牢、因子、处刑这些 IP 元素还在，但不再是叙事主体，只是渲染审判压力的环境。

## 二、完整题目样例集（覆盖四个模型）

### 【模型 S · 审判】S1 严厉度

**当前版本**（扮演）：
> 你被带入宅邸地下室的因子检测室。冰冷的仪器扫描过全身，机械女声宣读：「预备魔女编号确认——因子侵蚀率已达危险阈值。」你会：
> - 冷冷地盯着屏幕。数据可能有误差，我不接受一面之词。
> - 按她说的做，先配合检查。
> - 催动体内因子震碎那台机器——让它闭嘴。

**C 路径版本**（面对）：
```
┌─────────────────────────────────────────────┐
│  [审判庭。魔女因子在空气中隐隐闪烁。]          │
│                                                │
│  审判官翻开卷宗，头也不抬。                     │
│                                                │
│  「你一直觉得自己是个讲道理的人，对吧？         │
│   可是你心里清楚——有些人，你从一开始就没打算    │
│   给他们解释的机会。                           │
│                                                │
│   承认吧。你的'讲道理'，是有选择性的。」        │
│                                                │
│  ┌─────────────────────────────────────────┐ │
│  │ ……不承认。我对谁都是先听再说。             │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │ 你说得对。有些人，我不屑于讲道理。         │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │ 我不是有选择性。是有些人不配被讲道理。     │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**为什么逼视**：审判官不是问"你严厉吗"，他是**指控**"你的讲道理是虚伪的"。用户被迫选择——否认（可能心虚）、承认（暴露真实自我）、合理化（"是他们不配"）。每个选项都是一次自我立场声明。

### 【模型 F · 侵蚀】F1 复仇心

**当前版本**（扮演）：
> 你发现了导致你因子失控的人……此刻只有你们两个人……
> - 放过她吧。恨只会让因子侵蚀得更快。
> - 盯着她看了很久。手指攥紧又松开，最终转身离开。
> - 终于等到这一天了。这股恨意从没有消退过。

**C 路径版本**（面对）：
```
┌─────────────────────────────────────────────┐
│  [审判官的影子投在你身上。因子在你血管里躁动。] │
│                                                │
│  「别装了。                                    │
│                                                │
│   你嘴上说'放下了'，可你记得每一个伤害过你的    │
│   人的脸，记得他们说过的每一句话，记得当时的    │
│   天气。                                       │
│                                                │
│   你从来没有真正原谅过任何人——对吗？」          │
│                                                │
│  ┌─────────────────────────────────────────┐ │
│  │ 不对。我是真的放下了。记着不代表没放下。   │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │ ……你说得对。我只是假装放下了。            │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┘ │
│  │ 我从不假装。恨就是恨，我凭什么要原谅。     │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**为什么逼视**：这是最直白的灵魂拷问。审判官用"你记得每个人的脸、每句话、当时的天气"这种**极其具体的细节指控**，让用户无处可躲——因为人确实记得。三个选项覆盖了人类面对"你从未原谅"这个指控的三种真实反应：嘴硬否认、痛苦承认、理直气壮的恨。

### 【模型 B · 羁绊】B2 背叛感

**当前版本**（扮演）：
> 你发现最好的朋友一直在偷偷汇报你们的行动。被你质问时，她说她是为了保护你。
> - 每个人都有自己的立场。生气没用，先解决问题。
> - 愤怒和悲伤同时涌上来，但你强迫自己听完解释。
> - 心像被人用刀剜了一块。被最信任的人背叛，比因子侵蚀还痛。

**C 路径版本**（面对）：
```
┌─────────────────────────────────────────────┐
│  [你身后的镣铐无风自动。审判官的声音很轻。]    │
│                                                │
│  「你总说自己'很看重感情'。                    │
│                                                │
│   可我问你——上一次有人背叛你的时候，            │
│   你心里冒出来的第一个念头，真的是'难过'吗？     │
│                                                │
│   还是……'我早就知道了'？」                      │
│                                                │
│  ┌─────────────────────────────────────────┐ │
│  │ 是难过。被信任的人伤害，怎么可能不痛。     │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │ ……你猜对了。我第一反应是'果然如此'。      │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┘ │
│  │ 我不'看重感情'。我只是害怕被丢下。         │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**为什么逼视**：这道题逼视的不是"你被背叛怎么办"，而是**"你被背叛时的真实心理"**——审判官指出"你的第一反应可能不是难过而是'我早就知道了'"，这戳破了很多人对自我形象的维护（"我是重感情的人"）。三个选项分别戳向：维护自我形象、承认阴暗面、承认根本动机。

### 【模型 W · 觉醒】W1 压抑力

**当前版本**（扮演）：
> 深夜独处时，你突然想起所有被伤害的记忆。因子在悲伤中共鸣……你意识到情绪正在加速侵蚀。
> - 让眼泪流一会儿，但深呼吸控制住魔法输出。
> - 放手吧。让一切涌出来。
> - 握紧拳头，一个一个把记忆压回去。

**C 路径版本**（面对）：
```
┌─────────────────────────────────────────────┐
│  [空气变得粘稠。审判官第一次直视你的眼睛。]    │
│                                                │
│  「别人都以为你情绪稳定。                       │
│                                                │
│   但我知道——你不是稳定，你是在'压'。            │
│   你把所有东西都压在一个连你自己都害怕的地方。  │
│                                                │
│   我问你：那个地方，现在……还撑得住吗？」        │
│                                                │
│  ┌─────────────────────────────────────────┐ │
│  │ 撑得住。我没有在'压'，我只是看得开。       │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │ ……快撑不住了。有时候我自己都不知道在压什么。│ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┘ │
│  │ 我没在压。我只是觉得大多数事不值得有情绪。  │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**为什么逼视**：这道题逼视"情绪稳定"这个当代人最常见的自我伪装。审判官用"你不是稳定，你是在压"直接戳破。三个选项分别戳向：否认（维护"我看得开"）、脆弱承认（"快撑不住了"）、理性化防御（"不值得有情绪"）。

> 第18题，4选项，决定 destroy/endure/normal 路径。

**C 路径版本**（面对）——门控题应该是**最重的一记逼视**：

│                                                │

│                                                │

│                                                │
│  ┌─────────────────────────────────────────┐ │
│  │ 毁灭。我想把伤害过我的东西全部摧毁。       │ │  ← destroy 路径
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │ 被看见。我只是不想再一个人扛着。           │ │  ← endure 路径
│  └─────────────────────────────────────────┘ │

**为什么逼视**：门控题是整个测试的情绪高潮。它不问行为，问**最深处的欲望**——"毁灭还是被看见"是一个能让大多数人心头一震的二分。这个逼视直接决定用户走哪条审判路径。

## 三、交互变奏（配套机制，与 C 路径编织）

C 路径解决"面对自己"，但26题全是审判官逼问也会单调。穿插变奏题：

### 天平题（二选一迫选）—— 第8题、第22题

审判官放下卷宗，在天平两端放上两个"灵魂砝码"：
```
┌─────────────────────────────────────────────┐
│  审判官：「别想了。天平只会倾斜一次。           │
│           你骨子里，到底是——」                  │
│                                                │
│  ┌──────────────┐    ┌──────────────┐        │
│  │              │    │              │        │
│  │ 「宁愿被骗    │    │ 「宁愿孤独    │        │
│  │   也不孤单」  │    │   也不冒险」  │        │
│  │              │    │              │        │
│  └──────────────┘    └──────────────┘        │
│              二选其一，不可回头                 │
└─────────────────────────────────────────────┘
```
- 复用 ease-out-expo 曲线 + is-selected/is-dimmed 推开（左右两块）
- 选项是灵魂底色的二分，比三选项更迫人

### 砝码题（分量分配）—— 第14题

审判官给你"罪业之秤"，让你亲手称量自己：
```
┌─────────────────────────────────────────────┐
│  审判官：「这台秤，你来拨。                     │
│           把分量，给你心里真正认同的那句话。」    │
│                                                │
│  「为了在乎的人，我可以变成坏人」  [●●●] 3     │
│  「我永远不会原谅蓄意的伤害」      [●]   1     │
│  「比起被爱，我更怕失去自我」      [ ]   0     │
│                                                │
│  拖动分配 · 总和必须 = 3                        │
└─────────────────────────────────────────────┘
```
- 拖拽交互，与点选项完全不同
- 用户亲手"称量自己"的隐喻强化逼视感

## 四、中途反馈（配套机制）—— 审判官批注

每5题（第5/10/15题后），审判官停下，对你"说几句"。这不是氛围词（不输出维度），是**基于已答倾向的行为素描**：

**第5题后**（试探）：
```
┌─────────────────────────────────────────────┐
│  审判官合上卷宗的一页。                         │
│                                                │
│  「有意思。                                     │
│   你回答的时候，很少犹豫。                      │
│   这说明……你要么很清楚自己是谁，                │
│   要么，很擅长让自己看起来清楚。」              │
│                                                │
│  [继续审判]                                     │
└─────────────────────────────────────────────┘
```

**第10题后**（逼近，刚好在你"没耐心"的节点）：
```
┌─────────────────────────────────────────────┐
│  审判官停下笔。                                 │
│                                                │
│  「你到这一半了。                              │
│   但我注意到——有些题，你答得太快了。           │
│                                                │
│   快到像是……你早就想过这些问题。               │
│   还是说，你在回避真正去想？」                  │
│                                                │
│  [继续审判]                                     │
└─────────────────────────────────────────────┘
```

**第15题后**（审判，收束）：
```
┌─────────────────────────────────────────────┐
│  审判官站起身，走到你面前。                     │
│                                                │
│  「快结束了。                                  │
│   但有件事我得告诉你——                          │
│   你今天交出来的这些答案，                       │
│   有些……连你自己都没承认过，对吧？」             │
│                                                │
│  [最后一轮审判]                                 │
└─────────────────────────────────────────────┘
```

**为什么不是氛围词**：氛围词输出维度标签（"侵蚀加深"）→ 用户能逆推角色。审判官批注输出**行为素描**（"你回答时很少犹豫"）→ 无法逆推角色，但用户能感到"我被看见了"。三次递进：试探→逼近→审判。

## 七、需要你判断的

1. **灵魂拷问主歌的逼视感**：S1/F1/B2/W1/门控 这5道样例，是不是都让你觉得"我在被逼视"？哪道不够？哪道过了？
2. **审判官的"人设"**：现在审判官是冷静、洞察、步步紧逼的形象。这个调性对吗？还是要更温和/更压迫/更神秘？
3. **选项三态（否认/承认/狡辩）**：这个结构好不好？还是需要更多变化？
4. **变奏题（天平/砝码）+ 批注**：和灵魂拷问主歌编织在一起，你觉得节奏对吗？
