## D1. 流程结构：4 幕分块（来自 A，修补分组漏洞）
- 4 幕对应 S/F/B/W 四个维度模型组，各 6 题（Act IV 含门控+触发共 8 题）。
- **幕内强制打散**：每幕 6 题 = 3 正向 + 3 反向，正向在前反向在后，且同维度正反间隔 ≥2 题。
- 重排在**前端 RenderQueue 层**完成（不改 DB order 字段），由 `flow_structure` feature flag 控制，默认 `"acts"`，可回退 `"linear"`。
- 来源：A 的主干 + 修补 A 未识别的"题序非按模型聚类"问题。

## D2. 幕间反馈：提问式审判官批注（来自 A，砍掉氛围词）
- 3 个幕间过渡层（Act I→II、II→III、III→IV），每个含：(a) 幕标题卡片；(b) 审判官提问式批注 + 2-3 选项，**不计分**。
- ~~因子共鸣氛围词~~：**[用户决策] 暂时不做**（剧透风险与获得感不足两难，用户选择不做）。
- 过渡层独立于 700ms 单题动画，寄生于 flushPending 之后的叠加层，默认 1.5s 可点击跳过。
- 提问式批注用"提问式而非断言式"（如"你审判的手很稳。但典狱长想知道：这份严厉，是力量还是盔甲？"），不基于维度分做个性化断言。

## D3. 第二人称选项：括号内心独白（来自 A）
- option label 统一改为括号包裹的"你"的内心独白，主语"你"，去祈使动词，保留感受判断，分数不动。
- 符号按 locale 调整（zh 用全角括号，en 用半角，ja 用「」或全角）。
- 改 DB 的 Option.label + Question.translations（**[用户决策] 先做 zh-CN，en/ja/zh-TW 拆出去后续批量翻译**），**不是改 quiz-content.ts**。

## D4. 直问题：不计分纯叙事（来自 A，否决 B 的计分替换）
- 3 个直问题嵌在幕间过渡层（与 D2 共用），不计分、不进 dimScores、不影响 match。
- **不替换任何现有反向题**，维度覆盖维持 12×2。否决 B 的"加3删3+归一化"以守 R4。

## D5. 题序重排：前端 RenderQueue 确定性重排（来自 A，否决 B 的动态）
- 分幕顺序确定性（S→F→B→W），幕内按 D1 打散规则。无 clarity 动态排序。
- localStorage 仅存 currentIndex（与现状一致），不存 adaptiveOrder。

## D6. 门控/触发：保留原位（否决 A 的挪到 Act IV 末、B 的绝对位25/26）
- 门控（题18位）、触发（题19位）保留原数组位置，作为分幕结构中的"最终审判"叙事节点自然融入。
- gateValue/triggerFired 逻辑、applyGateBonus、条件渲染全部零改动。
- 理由：挪动门控位会改变用户疲劳度下的关键决策，影响特殊角色触发率，无方案分析过此连锁。

## 共同盲点（5 个）

### 盲点#1（致命）：三方案都误判了数据源
运行时题目来自 `db.question.findMany()`（api/quiz/route.ts），quiz-content.ts 只是 seed。改 seed 不会自动同步到已部署 DB。**所有内容改造（第二人称、分幕、直问）是 DB 层操作。**

### 盲点#2（高）：4幕与既成题序冲突
当前题序是 S1,F1,B1,W1 轮转混排（非按模型聚类）。分幕必须真正重排——改 DB order 或前端 RenderQueue。ADR 决策：前端 RenderQueue 重排（不改 DB order），可回退。

### 盲点#3（高）：i18n 改造成本被低估
4 语言（zh-CN, zh-TW, en, ja）。78 条 option × 4 = **312 条文案重写** + 幕标题/旁白/直问/氛围词词库。是内容创作瓶颈，非工程瓶颈。

### 盲点#4（中高）：感知提速无可证伪的 A/B 设计
主观指标（投入度、进展可感）无法直接测。需代理指标：完成率、题10/18/26放弃率、单题中位响应时长、结果页分享率。feature flag 切流，预设显著性阈值。

### 盲点#5（中）：降级/fallback 不彻底
内容改造可逆性最差。强制要求：DB 保留 original_label/original_order；流程结构用 feature flag；分幕在 RenderQueue 层做不改 DB。

## 实现优先级
1. **P0**（先做，可独立验证）：D3 第二人称选项改造（DB 内容，4 语言，最高 ROI，零结构风险）
2. **P1**：D1+D5 前端 RenderQueue 分幕重排（含 D6 门控原位适配），feature flag 控制，可 A/B
3. **P2**：D2 幕间过渡组件 + 氛围词映射表（依赖 P1 的分幕结构）
4. **P3**：D4 直问题内容（嵌在 P2 过渡层内）
5. **P4**：A/B 实验设施 + GA 监测

**明确不动**：match.ts、answer-processor.ts（D4 不计分）、api/match/route.ts、api/quiz/route.ts、700ms 时序常量（feedbackDelay=400/totalDelay=700/cubic-bezier/is-dimmed）。
