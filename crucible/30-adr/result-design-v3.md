# 结果页设计 v3 —— 揭晓时刻（用 interface-details skill 打磨动效）

> v2 的方向对（揭晓时刻、角色档案卡、砍百分比、稀有度），但动效细节是"想象"的。
> v3 用 interface-details skill 的具体规则，把每个动效决策落到可执行的细节。
> 每条动效标注对应的 skill 规则 ID（如 motion-18），确保"花哨"有据可依、有度可循。

---

## 〇、skill 给出的关键纪律（先立规矩）

interface-details skill 有一个"决策门"，动效必须通过才算合格：

1. **Serve the user, not the ego** —— 如果一个动效只是让设计师觉得酷，是装饰，砍掉。
2. **Frequency of exposure** —— 越高频的交互动效越要安静。结果页是**一次性/低频**的揭晓时刻，**可以承载 delight（惊喜）**——这是 skill 明确允许的。
3. **Respect the user** —— 必须支持 `prefers-reduced-motion`、键盘、触屏。
4. **Consistency** —— 动效语言要和题目的 ease-out-expo 曲线一脉相承。

**结论**：结果页是低频的、一次性的揭晓时刻，skill 允许它"花哨"。但花哨要有度——通过决策门，且和题目的动效 DNA 一致。

---

## 一、揭晓序列（结果页的第一秒，最关键）

答完最后一题 → 揭晓序列。按 **motion-18（Stagger reveals to set event order）**——多个元素进入时错峰，让眼睛有路径和顺序。

```
时间轴（每一步错峰，不是同时）：

t=0.0s   屏幕短暂暗下（0.8s）
         ↓ motion-7: 通过模糊淡出答题页，不是硬切

t=0.8s   「审判结束了。」  淡入浮现
         ↓ 短暂停顿（1.0s）让情绪沉淀

t=1.8s   「而你是——」  淡入
         ↓ 留白（0.6s），制造悬念

t=2.4s   角色名从模糊中浮现（motion-7: cross-fade through blur）
         用 ease-out-expo 曲线（和题目一致，motion 语言延续）
         大字号，从 scale(0.96) → 1.0，带轻微 blur 收锐

         二 阶 堂 希 罗

t=3.0s   标语浮现
         ↓ motion-3 灵感：标语可选逐字描出（stroke-by-stroke）
           像审判官亲笔写的判决词
         「哪怕要死一千次，我也要把她带回来」

t=3.8s   IP 出处小字浮现
         ───── 来自《魔女审判》─────

t=4.2s   角色档案卡整体可用（之前可点击跳过，见下）
```

**关键 skill 规则应用：**
- **motion-18（Stagger reveals）**：6 个元素按情绪顺序错峰，不是同时砸出来。眼睛跟着"判决结束→而你是→是谁→说什么→哪来的"走。
- **motion-7（Cross-fade through blur）**：答题页淡出和角色名浮现都通过模糊过渡，不是硬切。这是揭晓"有质感"的关键。
- **motion-3（Stroke-by-stroke）**：标语逐字描出，像手写判决。这是"仪式感"的核心动效。
- **ease-out-expo 曲线贯穿**：复用题目的 `cubic-bezier(0.16,1,0.3,1)`，动效 DNA 一致。

---

## 二、揭晓动画必须可打断（尊重用户）

按 **motion-11（Make animations interruptible）**——揭晓序列期间，**任意点击/按键即跳过到完整结果页**。

```
揭晓进行中 → 用户点击/按任意键 → 立即完成所有动画，展示完整角色档案卡
```

**为什么重要**：skill 明确说"阻塞输入直到动画结束会读起来像卡顿"。揭晓是好玩的，但不能强迫用户等 4 秒。急性子用户一点即过，享受仪式的用户可以看完。

---

## 三、角色档案卡（揭晓后的主体）

揭晓序列结束后，角色档案卡完整呈现。设计要点参考 **design 章节**的视觉打磨规则。

```
┌─────────────────────────────────────────────┐
│                                              │
│         二 阶 堂 希 罗                         │  ← 已在揭晓时浮现
│            HIRO                              │
│                                              │
│   「哪怕要死一千次，我也要把她带回来」          │  ← 已在揭晓时描出
│                                              │
│   ───── 来自《魔女审判》 ─────                │
│   一部关于"在死亡回溯中守住一个人"的故事        │  ← 一句话作品介绍（跨IP友好）
│                                              │
├──────── 滚动查看更多 ─────────┤               ← 暗示下方有内容
│                                              │
│   你是冰与火的矛盾体——外表冷酷无情……         │  ← 角色描述（滚动后）
│                                              │
│   灵魂特质                                     │
│   冷焰 · 死亡回溯 · 为挚爱不惜一切             │  ← 关键词标签
│                                              │
│   稀有度                                       │
│   ▓▓░░░░░░░░  全球仅 3.4%                    │  ← 稀有度条（非百分比相似度）
│                                              │
└──────────────────────────────────────────────┘

      [分享我的审判]    [重新审判]
```

**design 规则应用：**
- 滚动边缘用 **motion-6（Bleed blurred edges）**——内容在卡片内滚动时，上下边缘用模糊渐变而不是硬裁切线。
- 稀有度条用 **motion-22（Ambient indicator）**灵感——不是干巴巴的进度条，而是带一点环境光感（角色主题色的微光呼吸），让"3.4%"有质感。
- 按钮 hover 用现有风格（letter-spacing 变化 + 颜色），保持一致性（决策门#4 Consistency）。

## 四、隐藏角色的彩蛋动效（让特殊人格更惊喜）

按 **easter-egg#3（Reward the explorer）**——当用户匹配到**隐藏角色**（特殊人格，2 个），揭晓动画升级：

```
普通角色揭晓：角色名模糊浮现（motion-7）
              ↓
隐藏角色揭晓：屏幕先出现一道"裂缝"光效
              → 角色名带着粒子碎裂感浮现
              → 多一行彩蛋文案：「……审判庭从未见过这样的受审者。」
              → 稀有度显示「极少判定 · <0.5%」
```

**为什么**：隐藏角色是用户"探索"出来的稀有结果，值得用额外的动效惊喜奖励（easter-egg#3 的核心）。普通角色用克制的好动效，隐藏角色用更戏剧化的动效——形成"特殊感"。

## 五、分享卡（传播载体）

按 **design + copywriting 章节**打磨。分享卡是传播的核心，必须自带钩子。

```
┌────────────────────────┐
│                        │
│   [角色主题色渐变背景]   │
│                        │
│   我接受了灵魂审判。     │  ← copywriting: 钩子文案，引发好奇
│                        │
│   ─────                │
│                        │
│      二阶堂希罗          │  ← 角色名（大号，醒目）
│                        │
│   「哪怕死一千次，        │
│    也要把她带回来」      │  ← 标语
│                        │
│   来自《魔女审判》       │  ← IP出处
│                        │
│   全球仅 3.4%            │  ← 稀有度（游戏化）
│                        │
│   ─────                │
│   [来接受审判 →]         │  ← 二维码 + 行动召唤
│                        │
└────────────────────────┘
```

**copywriting 规则：**
- 钩子文案"我接受了灵魂审判"——比"我的结果是XX"更有悬念，引发"审判是什么？"的好奇。
- 行动召唤"来接受审判"——明确的传播闭环，不是干巴巴的"扫码"。

## 六、无障碍与降级（skill 决策门#3，必须做）

```
@media (prefers-reduced-motion: reduce) {
  /* 揭晓序列退化为简单淡入，无 stagger，无 blur，无 stroke */
  /* 角色档案卡直接展示，稀有度条不做呼吸光效 */
}

键盘支持：
  - 揭晓中按任意键跳过
  - Tab 可聚焦到 [分享][重新审判] 按钮
  - Enter 触发按钮

触屏：
  - 揭晓中点击跳过
  - 触摸目标 ≥ 44pt
```

## 七、v3 动效清单（实现时的 checklist）

| 动效 | skill规则 | 位置 | 必须/可选 |
|---|---|---|---|
| 答题页模糊淡出 | motion-7 | 揭晓开始 | 必须 |
| 文字错峰浮现 | motion-18 | 揭晓序列全程 | 必须 |
| ease-out-expo 曲线 | consistency | 所有动效 | 必须 |
| 角色名模糊浮现 | motion-7 | t=2.4s | 必须 |
| 标语逐字描出 | motion-3 | t=3.0s | 可选（性能权衡） |
| 动画可打断 | motion-11 | 揭晓全程 | 必须 |
| 滚动边缘模糊 | motion-6 | 档案卡滚动 | 必须 |
| 稀有度环境光 | motion-22灵感 | 稀有度条 | 可选 |
| 隐藏角色粒子揭晓 | easter-egg-3 | 隐藏角色专属 | 可选（先做普通版） |
| prefers-reduced-motion 降级 | 决策门#3 | 全局 | 必须 |

## 八、需要你判断的

1. **揭晓序列的节奏**（4.2s 总时长，可点击跳过）——太长？太短？还是正好？
2. **标语逐字描出**（像手写判决）——这个"仪式感"动效要不要？还是直接淡入就好？
3. **隐藏角色升级动效**（粒子碎裂 + 彩蛋文案）——这个惊喜要不要做？还是先统一动效？
4. **稀有度的"环境光呼吸"**——花哨到这个程度行吗？还是太过了？

整体来说：v3 的方向是"低频时刻允许 delight，但每条花哨都有 skill 规则背书，且尊重 reduced-motion"。这个度你觉得对吗？
