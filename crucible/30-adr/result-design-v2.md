# 结果页设计 v2 —— 揭晓时刻

> v1 全盘推翻。v1 的病根：用审判皮包装传统结果页，审判腔用力过猛，丢失好玩感，跨IP没处理好。
> v2 方向：结果页不是"判决书"，是**审判结束后的揭晓时刻**——情绪从逼视反转为惊喜，趣味浮现，适合传播。

---

## 〇、核心转变

题目和结果页是**两种不同的心理**，不该用同一种语言：

| | 题目（灵魂拷问） | 结果页（揭晓时刻） |
|---|---|---|
| 心理 | 逼视、面对、紧张 | 释放、惊喜、好玩 |
| 语言 | 审判官步步紧逼 | 揭晓、反转、趣味 |
| 用户感受 | "我在被审判" | "原来我是她！？" |

**v2 让结果页从"审判的延续"变成"审判的终点"——判决落锤那一刻，情绪反转。**

---

## 设计一：揭晓动画（结果页的第一秒最重要）

用户答完最后一题，屏幕不直接跳到结果，而是有一个**揭晓的瞬间**：

```
[答完最后一题]

  屏幕短暂黑屏（0.8s）
  
  然后一行字缓缓浮现：

        「审判结束了。」

  [1.2s 停顿，让情绪沉淀]

        「而你是——」

  [角色名从黑暗中以你最喜欢的那种 ease-out-expo 曲线
   "被推开/浮现"出来——复用题目动效的 DNA，但是揭示向]
   
        二 阶 堂 希 罗
   
  [标语浮现]
  「哪怕要死一千次，我也要把她带回来」

  [最后，IP 出处小字]
  来自《魔女审判》
```

**关键**：
- 复用题目的 `cubic-bezier(0.16,1,0.3,1)` 曲线和"文字浮现"质感——让揭晓和答题的视觉语言一脉相承，但情绪反转。
- **不做审判腔**——没有"判决书""受审者"这些用力过猛的词。就是干脆的"审判结束了，而你是——XXX"。干脆利落。
- 这个揭晓动画本身就是**可传播的内容**——用户会想录屏分享"我被判定为谁"的那个瞬间。

---

## 设计二：结果页主体 —— 「角色档案卡」而非「判决书」

揭晓动画结束后，展开完整的角色档案卡。**好玩、可读、可分享**，不是严肃的法律文书。

```
┌─────────────────────────────────────────────┐
│                                              │
│         二 阶 堂 希 罗                         │  ← 角色名（大）
│            HIRO                              │  ← 代码（装饰字体）
│                                              │
│   「哪怕要死一千次，我也要把她带回来」          │  ← 标语（斜体）
│                                              │
│   ───── 来自《魔女审判》 ─────                │  ← IP出处（带装饰线）
│                                              │
├──────────────────────────────────────────────┤
│                                              │
│   你是冰与火的矛盾体——外表冷酷无情，内心却    │  ← 角色描述
│   燃烧着比任何人都炽热的情感……                │     （第二人称，现有文案已是这样）
│                                              │
├──────────────────────────────────────────────┤
│                                              │
│   ╳ ╳ ╳ 的灵魂                              │  ← 灵魂关键词（标签式）
│   冷焰 · 死亡回溯 · 为挚爱不惜一切             │
│                                              │
├──────────────────────────────────────────────┤
│                                              │
│   👑 全球只有 3.4% 的人是她                   │  ← 稀有度（游戏化，好玩）
│                                              │
└──────────────────────────────────────────────┘

           [分享我的审判]  [重新审判]
```

**关键设计点：**

1. **角色档案卡 ≠ 判决书**——是"角色介绍卡"的质感，干净、好看、可截图。不是法律文书。
2. **IP 出处带装饰线**——"来自《魔女审判》"是重要信息（跨IP时用户需要知道角色出处），但用优雅的方式呈现，不是生硬标签。
3. **稀有度游戏化**——"全球只有3.4%的人是她"，这个比"相似度87%"好玩得多，也是传播点（"我是3.4%稀有角色"）。
4. **砍掉维度条/雷达图/百分比**——你说得对，百分比显得混乱。结果页只给"你就是这个人"+"这个人是谁"，干净利落。

## 设计三：跨 IP 角色的呈现（v1 没处理好的核心问题）

跨 IP 时，角色可能来自用户不熟的作品。v1 用审判语言包装，反而让陌生角色更突兀。v2 的处理：

### 情况A：用户匹配到熟悉的 IP 角色
直接展示，IP 出处只是装饰（如上面的魔女审判例子）。

### 情况B：用户匹配到不熟的 IP 角色
在角色档案卡里，**自然地介绍一下这个角色来自哪、是什么调性**：

```
┌─────────────────────────────────────────────┐
│                                              │
│           晓 美 焰                            │
│          AKEMI HOMURA                        │
│                                              │
│   「这一次，我一定会保护你」                   │
│                                              │
│   ───── 来自《魔法少女小圆》 ─────            │
│   一部关于"为了一个人反复重启世界"的故事        │  ← 一句话作品介绍
│                                              │
├──────────────────────────────────────────────┤
│                                              │
│   你是时间的主宰者——为了守护唯一重要的人，    │
│   你愿意在同一段时间里反复轮回，哪怕全世界      │
│   都忘了你的牺牲……                           │
│                                              │
└──────────────────────────────────────────────┘
```

**关键**：加一行"**一句话作品介绍**"——不是百科式的（"魔法少女小圆是2011年的动画…"），是**情绪式的**（"一部关于'为了一个人反复重启世界'的故事"）。这样即使没看过小圆的用户，也能get到"晓美焰"这种角色的味道，且产生"我想去看看这个IP"的冲动。

### 跨 IP 的视觉区分（可选）
不同 IP 的角色档案卡，可以有**微妙的视觉风格差异**：
- 魔女审判角色：暗黑哥特（现有风格）
- 小圆角色：略带几何/抽象（小圆的视觉符号）
- 毁灭者角色：废土/噪点质感
- 伊莉雅角色：明亮一点

这需要每 IP 有自己的 `theme` 配置。是加分项，非必需——**第一版可以全部用统一风格，视觉差异作为后续打磨**。

## 设计四：分享卡（传播的核心载体）

用户点"分享我的审判"时，生成一张**专为社交传播设计的图**：

```
┌────────────────────────┐
│                        │   ← 竖版，适合朋友圈/微博/推特
│   [背景：角色主题色]     │
│                        │
│                        │
│   我被审判了。           │   ← 钩子文案（引发好奇）
│                        │
│   审判结果是——          │
│                        │
│      二阶堂希罗          │   ← 角色名（醒目）
│                        │
│   「哪怕死一千次，        │   ← 标语
│    也要把她带回来」      │
│                        │
│   来自《魔女审判》       │   ← IP出处
│                        │
│   全球仅 3.4%            │   ← 稀有度
│                        │
│   [二维码：来接受审判]    │   ← 传播闭环
│                        │
└────────────────────────┘
```

**关键**：
- 钩子文案"我被审判了"+ 稀有度 + 二维码 = 完整的社交传播闭环。
- 没有"相似度82%"——只有"你就是这个人"+"你有多稀有"。
- 这张图就是用户想发朋友圈的东西。

## v2 vs v1 的对比

| | v1（推翻） | v2（本版） |
|---|---|---|
| 核心隐喻 | 判决书/法律文书 | **揭晓时刻/角色档案** |
| 情绪 | 延续审判的严肃逼视 | **审判结束的情绪反转，惊喜好玩** |
| 审判腔 | 用力过猛（CASE NO/受审者） | **几乎不用**，只在揭晓动画说一句"审判结束了" |
| 百分比 | 相似度排行（你否决了） | **砍掉**，用稀有度"3.4%"替代 |
| 跨IP | 审判语言包装（突兀） | **一句话作品介绍**（情绪式，勾起好奇） |
| 传播点 | 判决书截图 | **揭晓动画 + 稀有度 + 分享卡** |
| 维度数据 | 形态三保留了 | **砍掉**（你要干净利落的判决，不要百分比） |

---

## v2 保留的 / 砍掉的

**保留：**
- 角色名 + 标语 + 描述（第二人称，现有文案风格）
- 稀有度（游戏化，"全球仅X%"）
- 分享卡功能
- 重新审判

**砍掉：**
- ~~判决书格式（CASE NO/受审者/判决理由）~~——用力过猛
- ~~相似度百分比 / top3 排行~~——你说得对，混乱
- ~~维度条 / 雷达图 / 维度详情弹窗~~——干净利落，不要数据展示
- ~~审判官的最后判语~~——审判腔太重，砍
- ~~相近判决跨IP列表~~——馊主意，已否决

**新增：**
- 揭晓动画（"审判结束了。而你是——"）
- IP 出处 + 一句话作品介绍（跨IP友好）
- 分享卡重设计（稀有度+二维码，无百分比）

---

## 需要你判断的

1. **揭晓动画**（"审判结束了。而你是——[角色名浮现]"）——这个情绪反转的瞬间，对味吗？
2. **角色档案卡**（干净的角色介绍，非法庭文书）——比判决书舒服吗？
3. **砍掉所有百分比/维度条/雷达图**——这个决定你认同吗？还是觉得用户需要看自己的维度分布？
4. **跨IP的"一句话作品介绍"**——这个处理陌生角色的方式行吗？
5. **稀有度替代相似度**——"全球仅3.4%"比"相似度87%"好玩，你同意吗？
