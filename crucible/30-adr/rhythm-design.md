# 节奏变奏设计（v3 草案）—— 给用户看的具体设计

> 基于"交互形态单一 + 中途零反馈"两个真实痛点重新设计。
> 核心理念：把26题做成**有节奏编排的曲子**（主歌/副歌/变奏/华彩），而非26个一样的音符。
> 700ms 曲线+推开动效是"主歌"的标准动作——保持不变。新元素是"副歌/变奏"，有独立的交互形态。

---

## 设计总览：5幕节奏曲线

把原来的线性流程，编排成一条**情绪与交互的起伏曲线**：

```
幕1 立章(1-5题)    → 沉浸建立，全是场景主歌
  ↓ [过场A:审判官逼视] ← 第一次"不一样"，打破预期
幕2 深化(6-10题)   → 场景主歌继续，难度加深
  ↓ [自我镜像 #1]    ← 中途反馈：第一次"看见自己"
幕3 拷问(11-15题)  → 场景主歌 + 穿插"二选一迫选"变奏题
  ↓ [自我镜像 #2]    ← 中途反馈：第二次"看见自己"
幕4 抉择(16-20题)  → 门控题在这里，"分量题"变奏
  ↓ [自我镜像 #3]    ← 中途反馈：第三次"看见自己"（基于全部已答）
幕5 觉醒(21-26题)  → 场景主歌收束 + 触发题（条件）
  → 结果揭示
```

**关键：用户每隔5题左右就会遇到"不一样的东西"——要么是过场，要么是反馈，要么是新题型。这就是"新意"的来源。**

---

## 三个"打破单调"的具体机制

### 机制①：自我镜像（解决"中途零反馈"）

你砍了氛围词，但"中途看见自己"的需求还在。问题不是"要不要揭示"，而是"揭示什么才不剧透又勾人"。

氛围词的问题：它揭示的是**维度**（"侵蚀加深"）→ 高IP用户能猜到角色。

我的替代：**揭示"审判档案"——用审判IP的语言，而非心理学术语。**

每5题（共3次），弹出一个"典狱长批注"卡片，基于已答数据生成，但**只做定性描写，不给维度名/角色/百分比**：

```
┌─────────────────────────────────┐
│  📜 典狱长批注 · 第一轮审问后     │
│                                  │
│  「你的回答很有意思。             │
│   你不像其他人那样急于辩解，      │
│   也不像那些已经放弃的人。        │
│   你在......衡量什么？」          │
│                                  │
│  [继续审判]                       │
└─────────────────────────────────┘
```

**为什么这样不剧透又勾人：**
- 不说"你S维度高分" → 说"你不急于辩解"（行为描写，不是维度标签）
- 不说"你像HIRO" → 说"你在衡量什么"（提问式，引发好奇）
- 基于真实的维度分布生成，但翻译成审判官的叙事语言
- 每次都留一个悬念钩子（"你在衡量什么？""你真正害怕的，浮出来了""你和她们不一样"）

**3次的递进设计：**
- 第1次（5题后）：**试探性**——"你很有意思，不像其他人。"建立"我在被观察"的沉浸。
- 第2次（10题后）：**逼近性**——"你的面具出现了裂缝。你真正害怕的是什么？"戳到自我审视。
- 第3次（15题后）：**审判性**——"审判快结束了。但有些东西，你连自己都没承认。"勾向结果。

这套文案需要基于维度分做有限分支（比如3-4种人格倾向各一套），但**不输出任何可逆推角色的信息**——它输出的是"气质描写"，不是"数据揭示"。

---

### 机制②：题型变奏（解决"交互形态单一"）

在场景主歌（保持700ms动效）之间，穿插2种轻量变奏题。它们出现在特定位置，每次出现都是一次"新鲜感注入"。

**变奏A：二选一迫选（"天平题"）**——出现在第8题和第18题

不再是一个场景+3选项，而是**两个对立陈述，用户必须选一个**：

```
┌─────────────────────────────────┐
│         ⚖ 天 平                  │
│                                  │
│  ┌────────────┐ ┌────────────┐ │
│  │            │ │            │ │
│  │  「规则就是 │ │ 「规则就是  │ │
│  │   用来打破  │ │   用来守护  │ │
│  │   的」      │ │   人的」    │ │
│  │            │ │            │ │
│  └────────────┘ └────────────┘ │
│         二选其一                  │
└─────────────────────────────────┘
```

- 交互：左右两个大板块，选中一个→另一个被推开（**复用 is-selected/is-dimmed 推开逻辑和 ease-out-expo 曲线**，只是从3个变成2个、从纵向变左右）
- 计分：映射到2个维度的极值（如"打破"→低W1压抑+高W3本能；"守护"→高W1压抑+低W3本能）
- 出现2次，每次都是"终于不是老样子了"的新鲜感

**变奏B：分量题（"砝码题"）**——出现在第14题

不是选一个选项，而是**把有限的"分量"分配给2-3个陈述**：

```
┌─────────────────────────────────┐
│  你有3枚砝码。分配给你认同的：    │
│                                  │
│  「真相比安稳重要」  [○○○ ___] 3  │
│  「忠诚比自由重要」  [○___] 1     │
│  「生存比尊严重要」  [___] 0      │
│                                  │
│  拖动调整 · 总和必须=3            │
└─────────────────────────────────┘
```

- 交互：拖拽/点击增减砝码（一种全新的交互形态，和"点选项"完全不同）
- 计分：按分配比例映射到对应维度（最认同的=高分维度）
- 只出现1次，作为流程中段的"重头戏"，打破节奏

**这两个变奏题复用了 IP 语言（天平=审判、砝码=罪业之秤），不破坏调性，但交互形态完全不同。**

---

### 机制③：过场（解决"宏观节奏平淡"）

3个幕间过场（5题后、10题后、15题后），与机制①的自我镜像**合并**——过场卡片同时承载"典狱长批注"+ 章节标题。

过场本身不计分，1.5s自动消失或点击跳过。它的作用是**给用户一个"换气"的节点**，同时用叙事把流程切成段落。

## 保留了原方案的什么 / 改了什么

**保留（来自 v2 ADR）：**
- ✅ 第二人称内心独白选项（D3）—— 场景主歌的选项文案改造保留
- ✅ 不动 700ms 时序、曲线、推开视觉
- ✅ 不减题、不改匹配算法、门控/触发位不变
- ✅ feature flag 可回退
- ✅ i18n 先做中文

**改了（v3 调整）：**
- ❌ 砍掉"4幕维度模型分块"（D1）—— 不再按S/F/B/W分幕，因为分幕治不了你的痛点
- ✅ 改为"5段节奏曲线"——按**交互和反馈的起伏**分，而非按维度模型分
- ✅ 新增"天平题"（二选一迫选）和"砝码题"（分量分配）两种变奏题型
- ✅ 新增"典狱长批注"自我镜像（替代氛围词，用行为描写而非维度标签）

## 这个设计治你的痛点吗？（自查）

- **"交互形态单一"** → 26题里有3种形态：标准场景(20题)、天平迫选(2题)、砝码分量(1题)。每次遇到新形态都是新鲜感。
- **"中途零反馈"** → 3次典狱长批注，每次都"看见自己"一点，且用行为描写不剧透。
- **"做到第10题没新意"** → 第8题就是天平题（第一次变奏），第10题后是第二次自我镜像——刚好在你说的"没耐心"的节点注入变化。

**这个设计需要你判断的：**
1. 天平题/砝码题这两种新交互，你觉得"够不够打破单调"？还是太花哨？
2. 典狱长批注（行为描写式反馈）vs 你砍掉的氛围词（维度标签式反馈）——这个替代你接受吗？
3. 5段节奏曲线 vs 4幕分块——你更买哪个？
