## 润色守则

1. **题干 text**：场景一句话说清，去掉装饰性修饰语。保留场景的戏剧情境（这是测评沉浸感），但用大白话写。例："清晨，微尘在阳光里起舞。哪怕明知接下来又是令人作呕的一天，在那一刻，您心底浮现的声音依然是——" → "闹钟响了，新的一天又开始了。哪怕明知道今天大概率还是烂事一堆，你心里冒出来的第一句话是——"（注意本项目通篇用「您」，保持「您」）。
2. **选项主句**：保持简洁短句独白，把过于书面/抒情的地方改为口语。
3. **括号批注**：毒舌 + 口语。像朋友损你那样："（就信这个？挺好哄的。）"、"（哦，那你挺能忍的。）"——阴阳怪气也行，但必须是像人说话的阴阳怪气，不是戏剧腔。**避免**：四字成语连发、文言反问（"也罢/岂非/何其"）、感叹号三连。
4. **完全不动**：dim/meta/type/renderType/score/value/trigger、题号、选项数量、weight 题的 `weight::` 编码 label、GATE 题（Q18）的 value 文案结构、TRIGGER 题（Q19）的 trigger 逻辑。Q14 砝码题 options 是编码 label 不要改。Q8/Q22 scale 题选项的【】标签留意保留语义。
5. 字数：题干 ≤60 字，选项主句 ≤25 字，批注 ≤22 字。比现在短、比现在直。
