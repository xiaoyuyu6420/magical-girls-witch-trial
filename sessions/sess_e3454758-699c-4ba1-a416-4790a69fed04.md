**Q18 岔路口题：批注浮条遮挡了最后一个选项**

这是**布局冲突**：gate 题选项多 + 题干长 → 纵向空间不够 → 批注浮条和最后一个选项重叠。

---

### 修复方案

批注浮条的 `bottom: 7vh` 在选项多的题目上会越界。两个思路：

**A. 浮条改滚动容器内定位（推荐）**
把 `.interjection-overlay` 从 `position: absolute` 改成答题容器内的 `position: sticky; bottom: 0`，让它跟着内容流走，不会盖住选项。

**B. 浮条上移 + 缩小**
把 `bottom: 7vh` 改成 `bottom: 12vh`（给最后一个选项留空间），同时缩小字号和 padding。

**C. 批注浮条在 gate/trigger 题上改为顶部显示**
gate 题选项多，浮条改到题干下方显示，不跟选项抢底部空间。

## 引擎原理

不再是贴上去的光影，而是逐像素计算的真实折射：

- **位移贴图引擎**：CustomCursor 挂载时用 canvas 逐像素生成一张 168×168 的位移图——按球面透镜模型计算每个像素的采样偏移：**中心放大约 1.75 倍**、向边缘平滑衰减；最外 15% 半径叠加反向位移，形成玻璃厚边的**桶形畸变**折射环
- **合成器执行**：贴图注入 SVG 滤镜（`feImage` + `feDisplacementMap`），hover 时圆环的 `backdrop-filter: url(#witch-lens)` 让 GPU 合成器对背景内容实时折射——零 JS 每帧开销，跟手不卡
- **边缘质感三层**：贴图层的 rim 折射暗环 + CSS 内圈暗角（玻璃厚度感）+ 双圈金属描边（上一轮的质感保留）

**降级**：iOS Safari 等不支持 `backdrop-filter: url()` 的引擎自动回退为光影质感圈，不会报错或闪烁。
