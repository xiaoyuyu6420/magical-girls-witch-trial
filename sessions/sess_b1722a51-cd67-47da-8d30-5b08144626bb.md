## 之前为什么失败，这次怎么破的

I2 注释记录的 2 次失败（opacity 方案卡片不可见 / transform 方案 Playwright 99s flaky），**根因不是 animation 本质冲突，而是 className 随 state toggle → animation 反复重启 → 永远在 running → Playwright 持续判 not-stable**。

这次换了三招组合：

| 招 | 作用 |
|---|---|
| 题卡 `key={safeIndex}` | 切题时整个 remount，新 DOM |
| className 恒定含 `enter`（不 toggle） | animation 每次只在 mount 播一次，不重启 |
| CSS `backwards`（非 forwards） | mount 即 opacity:0 不闪第一帧；播完回归默认 opacity:1，`getAnimations()` 干净 → Playwright stability 在 ~0.6s 后通过 |
| `perspective:1000px` 加到容器 | 让 `rotateX(-10deg)` 有原版的 3D 倾斜效果（否则退化为 scaleY） |
