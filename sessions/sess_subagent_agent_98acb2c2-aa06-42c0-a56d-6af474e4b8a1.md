## 4. 调性建议（重写方向）

### 4.1 总调性：**审判官的逼视，是人味，不是戏腔**
方向已由 REDESIGN 锁定（用户共创确认"选 C 路径""F1 很有感觉"），重写要做的不是换模式，而是把模式从"像"做到"是"。三个抓手：
1. **每句指控必须携带一个具体细节**——"你是个虚伪的人"是无效指控；"你嘴上说'放下了'，可你记得当时的天气"才是逼视。重写题干时检查：删掉这句话里的细节（时间/地点/数字/身体反应/说过的话），它还剩什么？
2. **三态选项要有三种不同的"人"**——现状的中间态全是"我从不假装X"（同一个人的同一种嘴硬）。重写后三种回应应是三种人格：否认=硬（「我不认。规则就是规则」）、承认=痛（自剖、自嘲、破罐破摔）、中间=复杂（条件式让步、反问、承认一半）。分数语义不变，但声部要分开。
3. **中文质感：口语 + 逼问的混合体，拒绝翻译腔与网络梗**——基准是 REDESIGN 标杆「别装了。你嘴上说'放下了'，可你记得每一个伤害过你的人的脸」。短句、直呼"你"、用省略号和停顿制造压迫感。
