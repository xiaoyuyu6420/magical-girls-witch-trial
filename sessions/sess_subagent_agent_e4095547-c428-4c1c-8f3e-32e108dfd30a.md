## 问题 1【严重 / R8 违规】zh-CN.ts result 区残留"相似度类"语义，与 REDESIGN "砍掉所有百分比" 直接冲突

**具体影响**：REDESIGN 第 198 行明确要求"砍掉所有百分比/维度条/雷达图/top3 排行——百分比让确定性的判决退化成模糊的相似度比拼"，并强调"结果就是'你就是这个人'+'这个人是谁'，干净利落"。R8 契约据此要求清理"因子共鸣度/相似度类"。但 `src/i18n/zh-CN.ts` 第 38-41 行的三个 key 仍在用 `{percentage}%` 表达"有多少人和你一样"，这正是被否决的相似度语义：

```ts
statsInfo: "全球 {percentage}% 的被审判者与你相同（第 {count} 位 / 共 {total} 人）",  // 第38行
statsShort: "全球 {percentage}% 的被审判者与你相同",                                     // 第39行
factorResonance: "灵魂共鸣 {percentage}% — 与你命运相同的审判者",                        // 第40行 ← key名都是"因子共鸣"
factorResonanceLabel: "灵魂共鸣 — 与你命运相同的审判者",                                 // 第41行
```

**体验缺口**：判决本应是确定性的（"你就是二阶堂希罗"），但 `statsInfo` 给出的是"第 3124 位 / 共 89000 人"的排行榜味、`factorResonance` 给出的是"共鸣 87%"的模糊比拼——两个文案把 REDESIGN 反复强调的"确定性判决"又拉回了"相似度比拼"。而 `rarityGlobal: "全球仅 {percentage}%"`（第 48 行）是 REDESIGN 第 199-200 行明确保留的"稀有度替代相似度"，属于合法。问题在于"稀有度"与"共鸣度/相同占比"并存，用户会看到两套互相打架的数字系统。

**复现路径**：`src/i18n/zh-CN.ts:38-41`，对照 `docs/REDESIGN.md:198-200` 与 `crucible/10-intent-contract.md:34`(R8)。这三个 key（外加 factorResonanceLabel）应判定为死代码或待清理项，但它们没有被 zh-CN.ts 第 95 行那样标注"死代码"，处于"是否渲染"的灰色地带。

## 问题 3【中等 / 具体细节缺失】Q5、Q9 指控偏抽象，未达 REDESIGN"每句指控带具体细节（时间/地点/数字/身体反应/说过的话）"标准

**体验缺口**：Q2 能让用户"无处可躲"（REDESIGN 第 81 行原话），靠的就是"当时的天气"这种戳穿式的具体。Q5、Q9 这类题指控太泛，用户容易觉得"这是在描述一类人，不是我"，削弱 REDESIGN 第 53-56 行强调的"面对自己"的心理指向。
