你这个直觉非常准，而且点到了一个产品层面的大问题——**中间态是最尴尬的**：难受却没到深处，既不独特又劝退。就像恐怖片：要么吓到成为经典，要么轻松图一乐；"想吓人又不敢"的片子两头不讨好。

先拆清楚"难受"到底分两种：

- **看完会记住的难受**——被揭穿到骨子里，痛但"被看见"了，有情绪价值
- **只是不舒服的难受**——被戳了但没戳透，只留下不适感，没有回报

现在的题大部分停在第二种。原因是我写的时候**留了手**——为了"你觉得能接受"而收着，结果就是"戳了但没戳透"。狠，不是加更多细节，是**把留的手放下来**：从揭穿行为（"你咽着不说"）往下揭到动机和恐惧（"你怕一开口，就没人再爱你了"）。

## 我的推荐：更狠，但"聪明的狠"

狠 ≠ 每题都扎心。狠是可以**设计出来的**，配套机制让它"狠但能做完"：

1. **强度曲线**——不是每题的每个细节都下重手。前几题中等（建立审判语境），中段渐狠，**重题之间绝不连续**（绝望 Q6 后面接的题要轻，让用户喘口气）。
2. **三态本身就是出口**——被逼视但随时能"体面的逃"：否认（我没那么糟）、狡辩（合理化）都是心理退路。用户永远不会被逼到墙角没路走。
3. **变奏题是喘息**——天平（Q8/Q22）、砝码（Q14）是交互玩法，不是逼问，天然缓冲。
4. **批注插页 + 结果页接住**——每 5 题审判官停一下（喘息），结果页给救赎和共鸣（撕开之后要接住）。
5. **入口 content warning**——"本测验将直问内心敏感处，不适者可离开"——把"不想被问的人"筛在门口，他们不进来，就不存在流失。

这样"狠"是给**愿意被问的人**的礼物，而不是对所有人的折磨。

77	### Matching Algorithm — `src/lib/match.ts`
78	
79	This is the heart of the app. The flow:
80	
81	1. Collect dimension scores from answers (skip `GATE` and `TRIGGER` dims).
82	2. **Special trigger short-circuit**: if a `triggerFired` + matching `gateValue` (`destroy`/`endure`) is set, return a hidden character (similarity 100, `special: true`).
83	3. **Gate micro-adjustment**: `gateValue === "normal"` bumps `S2 +1`; `"normal_alt"` bumps `W1 +1` (caps at 6).
84	4. Convert each dim's summed score to a tier `L=0, M=1, H=2, X=3` via `ALGO_CONFIG.tiers`.
85	5. Weighted Manhattan distance vs. each non-special, non-fallback personality template vector (`"LHH-LLM-HHH-LLL"` format).
86	6. Sort ascending by distance, take top 3, compute similarity %.
87	7. **Border check**: if top1.similarity − top2.similarity < `ALGO_CONFIG.delta`:
88	   - If top1.similarity < `ALGO_CONFIG.threshold` → return the **fallback** type (group `"fallback"`, e.g. UNSET).
89	   - Otherwise mark result `borderType: true`.

58	1. **审判官作为逼视者出场**——不是NPC，是心理压力源，他的话直接指向用户本人。
59	2. **断言式逼问**——不说"你会怎么做"，说"你从来没有真正X过，对吧？"，用断言逼用户回应。
60	3. **选项是"承认/否认/狡辩"三态**——不是"选A还是B"，是"面对这个指控你怎么回应"。
61	4. **场景退为氛围**——监牢、因子等IP元素还在，但只是渲染压力的环境，不是叙事主体。
62	
63	### 标杆样例（F1 复仇心，用户确认"很有感觉"）
64	
65	```
66	审判官：「别装了。你嘴上说'放下了'，可你记得每一个伤害过你的
67	         人的脸，记得他们说过的每一句话，记得当时的天气。
68	         你从来没有真正原谅过任何人——对吗？」
69	
70	  ┌─────────────────────────────────────────┐
71	  │ 不对。我是真的放下了。记着不代表没放下。   │  ← 否认
72	  └─────────────────────────────────────────┘
73	  ┌─────────────────────────────────────────┐
74	  │ ……你说得对。我只是假装放下了。            │  ← 承认
75	  └─────────────────────────────────────────┘
76	  ┌─────────────────────────────────────────┐
77	  │ 我从不假装。恨就是恨，我凭什么要原谅。     │  ← 狡辩（合理化）
78	  └─────────────────────────────────────────┘
79	```
80	
81	**为什么逼视**：审判官用"你记得每个人的脸、每句话、当时的天气"这种极具体的细节指控，让用户无处可躲。三个选项覆盖了人类面对"你从未原谅"的三种真实反应。

83	### 其他维度样例（S1 / B2 / W1 / 门控）
84	
85	**S1 严厉度**——审判官指控"你的讲道理是虚伪的"：
86	> 「你一直觉得自己是个讲道理的人，对吧？可是你心里清楚——有些人，你从一开始就没打算给他们解释的机会。承认吧。你的'讲道理'，是有选择性的。」
87	> - ……不承认。我对谁都是先听再说。
88	> - 你说得对。有些人，我不屑于讲道理。
89	> - 我不是有选择性。是有些人不配被讲道理。
90	
91	**B2 背叛感**——戳破"我重感情"的自我形象：
92	> 「你总说自己'很看重感情'。可我问你——上一次有人背叛你的时候，你心里冒出来的第一个念头，真的是'难过'吗？还是……'我早就知道了'？」
93	> - 是难过。被信任的人伤害，怎么可能不痛。
94	> - ……你猜对了。我第一反应是'果然如此'。
95	> - 我不'看重感情'。我只是害怕被丢下。
96	
97	**W1 压抑力**——戳破"情绪稳定"的伪装：
98	> 「别人都以为你情绪稳定。但我知道——你不是稳定，你是在'压'。你把所有东西都压在一个连你自己都害怕的地方。我问你：那个地方，现在……还撑得住吗？」
99	> - 撑得住。我没有在'压'，我只是看得开。
100	> - ……快撑不住了。有时候自己都不知道在压什么。
101	> - 我没在压。我只是觉得大多数事不值得有情绪。
102	
103	**门控题（情绪高潮）**——审判官最终逼问，决定特殊角色路径：
104	> 「审了这么久，你一直在回答'你会怎么做'。现在我问最后一个——如果你拥有摧毁一切的力量，而且不会被任何人阻止……你心里那个最深的念头，究竟是想要'毁灭'，还是想要'被看见'？」
105	> - 毁灭。我想把伤害过我的东西全部摧毁。（→ destroy 路径）
106	> - 被看见。我只是不想再一个人扛着。（→ endure 路径）
107	> - 都不是。我想要的是平静地活下去。（→ normal 路径）
108	> - ……我还没想好。这两个我都想要。（→ 第四选项，触发用）
109	
110	**设计共性**：每道题都是审判官用具体细节指控一个关于用户的真相，选项是"否认/承认/狡辩（合理化）"三态，用户无处可躲必须亮明立场。

128	| F2 绝望度 | → | 绝望/韧性倾向 | 面对绝境的反应 |
129	| F3 执念度 | → | 执念/放下倾向 | 对目标的执着 |

172	### 跨IP匹配的核心问题
173	不同IP的角色，如何放在同一个通用心理维度空间比较？
174	
175	**答案**：每个IP的角色，都由人工（或内容作者）**按通用心理维度打分**，形成该角色的12维向量。比如：
176	- 魔女审判 HIRO：[复仇心高, 绝望中, 执念极高, 信任低, ...]
177	- 小圆 晓美焰：[复仇心高, 绝望高, 执念极高, 信任选择性, ...]
178	
179	两个角色虽然来自不同IP，但在同一套心理维度上有可比的向量。用户的答题向量与所有IP的所有角色向量计算距离，取最近的一个。
180	
181	**这是内容工作量**（每个新IP的角色都要人工标定向量），不是工程难题。算法本身（加权曼哈顿距离）零改动。
182	
183	### 跨IP匹配的匹配范围策略（待定）
184	- **全局匹配**：用户向量 vs 所有IP所有角色，取最近 → 结果可能来自任意IP（惊喜感强，但可能用户不熟的IP）
185	- **限定IP匹配**：用户先选IP，或系统按熟悉度筛选 → 结果可控
186	- **混合**：主结果限定，彩蛋可跨IP
187	**建议先全局匹配**（传播点在"跨IP惊喜"），但需观察用户反馈。

191	## 五、结果层：揭晓时刻（角色档案卡 + 动效揭晓）
192	
193	### 心理契约的转变
194	题目要逼视（面对自己），但**结果页不该继续逼视**——结果页是审判结束后的揭晓时刻，情绪要从紧张反转为惊喜好玩。用审判腔包装结果页是用力过猛（v1/v2 被否决的教训），结果页应该干脆利落。
195	
196	### 核心原则
197	- **结果页 = 揭晓时刻**，不是判决书。情绪从逼视反转为惊喜。
198	- **砍掉所有百分比/维度条/雷达图/top3 排行**——百分比让确定性的判决退化成模糊的相似度比拼，显得混乱。结果就是"你就是这个人"+"这个人是谁"，干净利落。
199	- **稀有度替代相似度**——"全球仅 3.4%"比"相似度87%"好玩，是游戏化传播点。
200	- 保留角色匹配（核心卖点）+ 分享卡功能 + 重新审判。
