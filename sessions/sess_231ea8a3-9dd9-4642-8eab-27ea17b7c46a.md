## 结论

**桌面排版变差的根因找到了并已修复**：8 月 14 日按你给的 HTML 32 原型做视觉重做时，`globals.css` 引入了 CSS layer 分层，其中一个层叫 `base`——和 Tailwind 内部的 `base` 层撞名，导致它的优先级位置被“劫持”，排在 reset 层之前。结果 reset 层的 `* { margin: 0; padding: 0 }` 反过来清零了基础样式里所有 padding/margin——**题目文字贴满 1440px 全宽、顶栏贴顶**，这就是你觉得“排版差很多”的主因。另外题目字体和行距也被换掉了（等宽 Space Mono → 宋体、1.6 → 1.9 行高）。

## 对比结果（旧版 GitHub ≈ 本地 8 月 8 日版）

先说明版本关系：GitHub 远程停在 6 月 17 日，但远程→本地最后一次提交之间桌面样式只差 4 行，所以“以前的桌面排版”= 本地 HEAD，我用 git worktree 把它拉到旁边跑了实物对比。差异只有两类：

1. **padding 被清零**（bug，上面说的 layer 撞名）——题目区、顶栏全部贴边
2. **题目排版参数**——字体、行高、字距被 reskin 改掉

而三列选项布局、挤压动效、罗马数字水印这些当时就特意保留了，两边本来就一致。

## 做的修改（都在 `globals.css`，共两处小改）

1. `base` 层改名 `app-base`（声明行 + 开层处 + 注释说明原因）——题目区 padding 恢复成和旧版一字不差（`6vh 8vw 3vh`），顶栏边距也自动恢复
