## 核心思路：结果页 = 审判官的当庭宣判

现在结果页是"角色名片"——平铺信息。但这和题目里的审判张力断了。**用户刚被审判官深度逼视，结果页应该变成审判官当庭宣判"你是谁"。**

我用 HIRO（冰与火的矛盾体）作为统一例子，做了三种形态给你对比：

---

### 形态一：审判判决书
用法律文书语言包装——CASE NO、受审者、判决、判决理由。审判官在宣判前先说一句针对用户的判语：

> 「我审过很多人。但你是第一个……让我分不清你是在隐瞒，还是真的不知道自己是什么样的人。」

然后才是"**你被判定为：二阶堂希罗**"。跨 IP 角色标注"来自《魔女审判》的镜像原型"。

### 形态二：审判官独白式（最沉浸，最激进）
零数据展示，整个结果页就是审判官的一段独白，把用户和角色连起来：

> 「你和那个叫'二阶堂希罗'的人，是同一种生物。她也是——外表冷得像冰，心里烧着火。她也是……宁可粉身碎骨，也不肯说一句'我需要你'。**你和她，是同一道伤口长出来的。**」

角色名只在最后浮现。**完全没有维度条/相似度/雷达图**。

### 形态三：双面判决（我推荐这个）
正面是**可分享的判决卡**（审判官金句+角色名+IP出处），翻转后是**完整数据**（维度分布+跨IP相近角色）：

```
正面（可截图分享）：           翻转后（点击展开）：
┌───────────────────┐         ┌───────────────────┐
│    审 判 判 决      │         │   完整审判记录      │
│                    │         │  复仇心 ▓▓▓▓▓▓▓ 极高│
│ 「你和她，是同一道   │   →     │  执念度 ▓▓▓▓▓▓▓▓极高│
│  伤口长出来的。」    │  翻转   │  相近判决：         │
│                    │         │  晓美焰(小圆) 82%  │ ← 跨IP传播点
│  二阶堂希罗 / HIRO  │         │  橘雪莉(魔女) 76%  │
│  来自《魔女审判》    │         │                    │
└───────────────────┘         └───────────────────┘
```

**为什么推荐形态三**：
- 正面"审判官金句+角色+IP出处"是最佳传播载体
- 翻转后"相近判决"列表**天然跨 IP**——"我的相近判决居然有晓美焰"，二次传播拉满
- 兼顾沉浸党（看正面）和数据党（看翻转）
